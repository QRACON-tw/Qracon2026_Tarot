### K4. 物理校稿者

簽核前頁尾只寫「附有科普說明」，不寫「已確認」。OG 圖要等簽核後才產生正式版（文案會燒進圖裡）。

## 影響設計

### K5. 流量統計

建議：用不設 cookie 的統計，只看頁面瀏覽次數。主站目前沒有任何統計工具；部署已改到 GitHub Pages，原本考慮的 Cloudflare Web Analytics 需另外加 beacon script。

**不擋上線**。採用與否會影響 `01` §10 最後一句。

### Q4. 五張牌改名

原文的牌名與它標的量子概念對不上，v2 已改名：

| 原牌名 | v2 | 理由 |
| --- | --- | --- |
| 量子糾纏純愛戰士 | 糾纏態純愛戰士 | 格式統一（概念＋角色） |
| 絕對零度冷酷貓 | 觀測者冷酷貓 | 絕對零度是熱力學，不是測量 |
| 量子躍遷幸運星 | 躍遷幸運星 | 格式統一 |
| 高能塌縮災難大師 | 淬火災難大師 | 「高能塌縮」不是標準術語 |
| 全光子熱情太陽貓 | 相干光太陽貓 | 「全光子」不是形容詞 |

其中三張是物理修正，兩張是格式統一。插畫內不放牌名（`04` §1），所以改名不影響插畫；需要主辦或行銷組確認新牌名可以對外使用。

### Q5. 「運勢」這個詞

牌義頁目前用「最近的運勢」，有人會讀成命理預測。替代方案：「最近的狀態」。更準，但少了一點占卜的趣味。

**影響**：七張牌的欄位標題。

### Q7. 牌背紋樣與全頁墨底

- 牌背紋樣：預設從字標 PNG 裁切「O」，設計組可在 11/20 前改交向量版（`04` A2）。
- 全頁墨底：主站沒用過的反相場景，**設計組須在 11/18 前確認**，否則改用紙灰底（`04` A3）。
