## 4. 三階段

### 第一階段：洗牌

- 七張牌背朝上，扇形展開。
- 牌背一致：墨底、銀墨高光、干涉線紋、主視覺紋樣（原文要求「每張牌背都有年會主視覺的圖案」，紋樣來源見 `03` Q7）。**七張牌背不可有編號或差異**，否則翻開前就能分辨。
- 進場：由中心聚合 → 扇形展開，每張間隔 40ms，只播一次。
- 牌的位置每次載入都重洗（見 `02-plan.md` §6.2）。

### 第二階段：觀測／塌縮

| 時間 | 事件 |
| --- | --- |
| 0ms | 使用者按下其中一張，輸入上鎖，同時 prefetch 目標頁 |
| 0–520ms | 其餘六張淡出（Should：改為碎片飛散） |
| 120–700ms | 被選的牌轉正、放大 1.08、邊緣亮一次 |
| 700–1300ms | 翻牌（Y 軸 180°），牌面出現 |
| 1300ms | 導向 `tarotPath('deck/[slug]/?draw=1')`，用 View Transition 把牌展開成票券 |
| 1600ms | 保底：還沒導頁就直接跳頁，不顯示訊息 |

## 6. 契合度對照表

夥伴與相剋都是**單向**關係（「你的夥伴是 X」不代表「X 的夥伴是你」），介面不可寫成「互相」。

| 牌 | 最佳量子夥伴 | 最強相剋量子 |
| --- | --- | --- |
| 愚者 | 命運之輪 | 隱士 |
| 戀人 | 太陽 | 死神 |
| 隱士 | 死神 | 太陽 |
| 命運之輪 | 愚者 | 死神 |
| 死神 | 隱士 | 命運之輪 |
| 塔 | 愚者 | 太陽 |
| 太陽 | 戀人 | 隱士 |

互為夥伴（雙向）：愚者↔命運之輪、戀人↔太陽、隱士↔死神。
互為相剋（雙向）：隱士↔太陽、死神↔命運之輪。
單向：愚者剋隱士、戀人剋死神、塔剋太陽、塔→愚者（夥伴）。

> 編輯註（不對使用者顯示）：塔沒有 incoming 夥伴。這是刻意的，不補關係、也不在介面上提這件事。

### 與原文的差異

原文的戀人相剋是隱士；v2 改為死神（退相干切斷糾纏，物理對應最強；隱士已有愚者、太陽兩個相剋）。其餘六組維持原文。

v2.2 改寫了三條理由，避免把糾纏或相干寫成通訊管道（戀人↔太陽），以及把弛豫說成退相干（命運之輪剋死神）。

## 12. 文案規則

1. **不用 emoji**。要標示就用文字（`夥伴`、`相剋`、`附註`）。
2. **一句最多一個驚嘆號**，只在角色引言裡。目前全篇 0 個。
3. **不用「打造」「賦能」「極致」「滿滿」「絕對」「一秒」**這類空泛強度詞。
4. **不用「歡迎隨時」「有任何問題都可以」**這類討好句。
5. **「不是 X，而是 Y」只在糾正真實誤解時用**（例如「退相干抹掉的是對比，波沒有變成直線」「讓糾纏斷掉的是環境，不是距離」）。只是為了抬高語氣的一律改直述。
6. **不承諾未確認的功能**（見 §7 獎勵區塊）。
7. **物理名詞要正確**，比喻要標明是比喻。不寫「被看見」造成塌縮，寫「被測量」。
8. **句子長度**：介面標籤 ≤ 12 字，內文一句 ≤ 40 字，一句定義 ≤ 24 字，科普註 ≤ 70 字。
9. **人稱**：對使用者用「你」，不自稱「我們」（除了關於頁的製作說明）。
10. **破折號少用**：全篇 `——` 不超過 6 處，其餘改逗號或句號。
11. **不用省略號**收尾。要停頓就換句。
12. **標點**：中文內文用全形標點，斜線用全形「／」。
