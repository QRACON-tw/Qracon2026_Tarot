## 1. 共同規則（所有圖像素材）

| 規則 | 說明 |
| --- | --- |

### 2.1 A1　七張牌面插畫

**不擋上線**：插畫沒到，網站用字體牌（羅馬數字 + 線稿圖示 + 直排牌名）上線，插畫到了只換圖、不動版面。

**期限**：

- **11/28**：趕得上 12/02 正式上線（11/28–29 是真機測試期，可以一起換）。
- **12/05**：最晚。12/06 程式凍結後不再換圖，插畫改成活動後再上。
- 可以分批交，到一張換一張。

**規格**：

| 項目 | 值 |
| --- | --- |
| 張數 | 7 |
| 尺寸 | **1440 × 2520 px**（4:7） |
| 格式 | 灰階 PNG，**滿版**（含牌面白底）；另附 SVG 線稿（可選） |
| 底色 | 純白 `#FFFFFF`（網頁牌面是白色，邊緣要接得上） |
| 單張上限 | 400 KB（交付檔）。網站會轉成 AVIF，上線檔 ≤ 90 KB，由工程處理 |
| 線條 | 縮到 330 px 寬（結果頁牌面約 20rem）時，最細的線仍要看得見：原圖線寬建議 ≥ 6 px |

**安全區**（網頁會在牌面上疊外框、內框、羅馬數字與牌名）：

```
┌────────────────────────┐  ← 1440 × 2520
│ ░░░░░░ 上 14% ░░░░░░░░ │  ← 網頁排羅馬數字，保持白底、不放主體
│ ░┌──────────────────┐░ │
│ ░│                  │░ │  ← 左右各 8% 不放主體（內框）
│ ░│     主體區        │░ │
│ ░│                  │░ │
│ ░└──────────────────┘░ │
│ ░░░░░░ 下 14% ░░░░░░░░ │  ← 網頁排牌名，保持白底、不放主體
└────────────────────────┘
```

以像素計：上方 y 0–353、下方 y 2167–2520、左右 x 0–115 與 x 1325–1440；主體區為 (115, 353)–(1325, 2167)，1210 × 1814。參考底圖見 [`assets/tarot-card-template.png`](assets/tarot-card-template.png)。

背景紋理可以延伸到安全區，但不能有主體或深色大塊，否則疊上去的文字讀不到。安全區比例是工程提案，設計組可以在動筆前提出調整。

**畫面上要避開的物理誤會**：

- 隱士：不要畫出「−273.15 °C」這個數字（絕對零度到不了），寫「~10 mK」或不寫。
- 死神：干涉條紋要「對比漸淡、變成均勻灰」，**不是**波變成一條直線。
- 太陽：「彩虹光束」用灰階明度階層表現，不上色。
- 塔：閃電打塔是塔羅構圖，不要畫成冷凍機爆炸、磁鐵冒煙。
- 戀人：兩貓之間的線是「同一條」，不要畫成訊號從一邊傳到另一邊的箭頭。

**可以出現的場景小字**：錯誤視窗、「檔案尚未儲存」這類笑點文字可以畫，但不能承載必要資訊。

**參考**：原文提到「傳統塔羅牌面會放旁邊」是給插畫師參考構圖用的，網站不顯示傳統牌面。

**驗收**（工程收到後檢查）：

- [ ] 1440 × 2520、PNG、≤ 400 KB
- [ ] 全圖最高飽和度 ≤ 0.02
- [ ] 上下 14%、左右 8% 沒有主體
- [ ] 縮到 330 px 寬時線條與主體仍可辨識
- [ ] 圖內沒有牌名、羅馬數字、角色名

### 2.2 A2　牌背紋樣

七張牌背**完全相同**（不能有任何差異，否則翻開前就能分辨）。原文要求「每張牌背都有年會主視覺的圖案」。

| 選項 | 做法 | 誰做 |
| --- | --- | --- |
| **預設** | 從主站字標 `qracon-wordmark.png`（1696 px 寬）裁出「內有四點方框的 O」，45° 重複排列 | 工程，不需設計組 |
| 升級 | 設計組出主視覺紋樣的向量版 | 設計組 |

升級版規格：

| 項目 | 值 |
| --- | --- |
| 格式 | SVG，單色（`fill="currentColor"` 或純白），無底色 |
| 拼接 | 可無縫平鋪（四邊接得起來） |
| 單元大小 | 在 88 px 寬的牌背上要能看出圖形（單元約牌寬的 1/4） |
| 檔名 | `tarot-back-pattern.svg` |
| 期限 | **11/20**（P2 開始做牌扇） |

牌背的其他層次（墨灰底、銀墨掃光、干涉細線）由工程用 CSS 疊，設計組只需交紋樣。

### 2.3 A3　全頁墨底方向確認

網站採「暗房」方向：全頁墨黑底、牌面紙白、零色相（`02` §3）。主站只有局部墨色區塊，從沒做過全頁墨底，需要設計組確認：

- [ ] 同意全頁墨底（A 暗房）；或
- [ ] 改用紙灰底（B 印刷廠，與主站一致，翻牌張力較弱）。

**期限 11/18**：牌扇與結果頁的配色在 P1（11/18–19）就要定。

## 6. 不需要的素材

以下不要做，避免設計組白工：

| 素材 | 原因 |
| --- | --- |
| 音效 | 不做（`03` Q8）：公共場合突然出聲是負評來源 |
| 彩色版、霓虹配色 | 違反 Zero Hue Rule（原文的賽博霓虹方向已否決） |
| 動畫檔（Lottie、GIF、影片） | 動畫全部用 CSS 做，且要能被 reduced-motion 關閉 |
| 3D 模型、WebGL 素材 | 非目標 |
| 傳統塔羅牌面圖 | 網站不顯示（著作權與風格衝突） |
| IG 限時動態分享卡模板（9:16） | 設計組不需要交模板：2026-11-23 起，七張限動圖由工程用 `scripts/build-story.mjs` 產生（`public/story/`，`02` §9.2）；結果頁第一屏仍可直接截圖 |
| 首頁主視覺大圖 | 首頁就是牌扇，不需要 hero 圖 |
