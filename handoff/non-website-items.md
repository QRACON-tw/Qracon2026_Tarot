## 2. 印刷品與 QR（H4）

網站團隊之前整理的建議，供印刷負責人參考：

| 項目 | 建議 |
| --- | --- |
| QR 內容 | 塔羅首頁 `https://qracon.entangletech.tw/Qracon2026_Tarot/`（repo `QRACON-tw/Qracon2026_Tarot`；印刷前先確認已部署可開）。指首頁邀人來抽，不要指向單張牌 |
| 網址 | **印出去就不能改**。送印前先確認正式網址 |
| 最小尺寸 | 印刷 ≥ 2.5 cm；海報掃描距離 1 m 以上時 ≥ 5 cm |
| 靜區 | 四周留白 ≥ 4 格模組 |
| 顏色 | 純黑碼、純白底，不反白、不在碼上加圖案 |
| 碼下方 | 印短網址，掃不到的人可以手打（短網址服務與管理人需另定） |
| 打樣 | 用 iOS、Android 至少各兩支手機實掃 |
| 時程 | 網站 12/02 正式上線；印刷品若要在活動前發放，建議 12/01 前送印 |

QR 圖檔：可以用任何 QR 產生器，或請網站工程用網站同一支腳本產生 SVG（黑白、靜區 4 格）。

## 3. 活動當天現場（H5）

網站本身是靜態站，放在 GitHub Pages，容量不是問題；網站團隊當天只負責「不部署」與「必要時回滾」。現場的部分建議：

- 12/11 或 12/12 到場地測一次 Wi-Fi 與 4G，順便實掃印刷品上的 QR。
- 準備印有短網址的小卡，掃不到 QR 的人可以手打。
- 場地網路若擁塞，請引導與會者改用行動網路。
