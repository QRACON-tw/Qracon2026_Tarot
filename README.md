## 一頁摘要

**是什麼**：手機優先的互動。七張牌背朝上的塔羅牌扇形展開，點一張，其餘六張散去，被選的那張翻開，接著展開成一張票券狀的「量子狀態觀測報告」。30–60 秒完成，最後導向議程與報名。

**網址**：`https://qracon.entangletech.tw/2026/tarot/`（主站 GitHub Pages 部署的子路徑）。

**技術**：寫在主站 repo 裡，Astro 7 靜態輸出、零框架、原生 CSS。字標、躍貓、字型、tokens、`Ticket` 等元件直接共用，連結走主站的 `sitePath()`。沒有 WebGL、沒有動畫函式庫。

**視覺**：暗房（墨黑場 + 紙白牌面 + 銀墨高光，零色相）。初稿曾建議全像箔，經審核查證主視覺飽和度為 0 後刪除。見 `02-plan.md` §3。

**時程**：11/27 軟上線（noindex、無入口）→ **12/02 正式上線** → 12/06 程式凍結 → 12/13 活動日。範圍分 Must／Should／Later，Canvas 分享卡與碎裂動畫不在 Must。

**做過的事**：

- 梳理原文：移除 6 種 7 處 emoji、16 條誇示／討好語、3 組重複段落；修正 3 張牌名與概念不符（例如「絕對零度」配「波函數塌縮」）與多處物理錯誤。
- 把 5 項未證實的產品承諾（QXP 幣、SSS 稱號、NFC 徽章、冒險者系統、分享到 IG）標成待確認，不寫成既成事實。
- 送 Gemini 4 審核兩輪（v2.1 核定）。
- 實作前審查（v2.2）：三路子代理掃描 + 顧問複審，發現部署方案 A 不可行、3 處物理錯誤、12 條規格漏洞；拉下主站最新版後，依 GitHub Pages 部署實況重寫部署章節。
